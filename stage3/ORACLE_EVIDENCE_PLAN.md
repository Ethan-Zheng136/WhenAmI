# 真实Future为何没有明显增益：分解诊断

2026-10-02，执行前固定。不是又一种可部署架构，不更改R+K正式结果。

1. 先只训练K的真实C_F oracle路径，取消学生混合损失与R。
   初始化、K结构、batch、LR、随机动作噪声与已有普通K相同，1000步。
   这检查“oracle/student共用K训练”是否压制了老师，不把失败全部归于R预测。
2. 若仍没有一致增量，比较投影前H_F与投影后C_F的信息：
   相同1024D输入K，对照真实H、由C通过已知W伪逆恢复的H、训练均值H、
   以及把未来帧替换为当前帧后重新编码的static H。
   恢复H的缺失坐标固定为训练均值，不使用逐样本真实H。
   所有H组共用真实H的训练集统计和同一结构，避免直接比较32D/1024D头的参数量。
3. static H控制额外Future编码器对当前图像的表征能力，不将“多了一个编码器”
   误算作真实未来的信息。静态控制是重新提特征，不伪造H。

统一：813训练/211验证窗口，seed42、batch8、LR1e-4、1000步最终checkpoint；
只训练K，只用冻结Past DiT的action FM，无alignment/distillation/rollout辅助。
评测保持同样逐窗口seed和9个Euler区间，保存全部预测及次指标。
仍是探索性单种子验证，不能证明“未来永远没用”或“过去在所有任务上足够”。
