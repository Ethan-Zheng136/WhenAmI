### 1a. VFMF — 最直接的理论论证 + 量化

| 项 | 值 |
|---|---|
| arXiv | **2512.11225** |
| URL | https://arxiv.org/abs/2512.11225 |
| 标题 | *VFMF: World Modeling by Forecasting Vision Foundation Model Features* |
| 提交 | **2025-12-12** (v1) |
| Comments 场 | **(none)** — 无 venue |
| 代码 | **未见公开链接**（abs 页无 github/项目页；只有 arXiv 的 "Code Finder" 通用挂件）→ **标记为无公开代码** |

**机制（我从 HTML 正文 §3.1 抄的原文）**：
> "regression-based methods predict future features $f_{t'}$ and, if trained to minimize the $\ell_2$ loss, **approximate the conditional mean $\mathbb{E}[f_{t'} \mid f_{1:t}]$**. In general, but **in particular when $T$ is small (e.g. 1–2 frames), the state of the scene is underdetermined since many futures are plausible**. **对 WoG 的三条精准命中**：
1. **"context 越短越糟"** — WoG 部署时 z 只来自**单帧当前观测**（$T=1$，比 VFMF 说的"1–2 帧"还苛刻）。这是该论证适用性最强的极端。
2. **"PCA 压缩次优"（§4.2）** — 原文：*"low-rank PCA … incurs noticeable information loss … PCA performs significantly worse than VAE on downstream dense prediction"*；同时 *"high-rank PCA preserves fine-grained details but reintroduces geometry artifacts"*。**这条直接反驳"就把 O^c 投到 top-8 主方向"这条看似显然的路**（见候选四）。
3. **"低维扩散更容易"** — 原文：*"diffusing 16 channels significantly outperforms diffusing DINO features directly … strongly supports the hypothesis that low-dimensional diffusion is easier."* WoG 的 O^c 是 [16,32]，**已经就在这个甜区**（32 通道 vs VFMF 用的 16）。→ **WoG 不需要再训 feature-VAE**，qformer 的 `v_proj:1024→32` 已经是那个压缩器。这让本 graft 从"要加一个 VAE"降级为"只改一个头"。

**机制（HTML 正文 Stage 1，我抄的 Eq. 8-10）**：

**消融数字（正文 "Future representation analysis"，我抄的原文）**：

翻译到 WoG 的语言：确定性回归让预测的各步之间**方向过度相似**（=坍缩到均值），且**预测的变化幅度只有 target 的 45%**（=幅度被平均掉了）。流匹配把幅度保真度从 0.45 拉到 0.80。**"change-magnitude 0.45"就是"回归到均值"的可测量指纹** — 这个指标用户可以在自己的 Stage-II checkpoint 上直接算，见文末实验。

### 2a. Barlow Twins — 交叉相关矩阵对齐

| 项 | 值 |

### 诊断预测（用数字论证）

**这是我对秩-18 问题的首选，理由是可以算出来的**：

- 当前 cosine 损失对 [B,16,32] 求 `.mean()`，等价于对 512 个坐标**均权**。O^c 秩 18 → **512 维里有 ~494 个方向几乎全是噪声**。若谱按典型幂律衰减，top-8 方向占方差的绝大部分，那么**均权 MSE/cosine 的梯度里，指向"动作相关子空间"的分量被稀释到个位数百分比**。这正是"3 倍提升但绝对值只有 0.177"的一个自洽解释：oformer 大部分容量在学 494 个噪声方向。
- 白化 / 去相关**把这个比例反转**：Barlow 的 on-diagonal 项让每个（去相关后的）方向都被要求匹配，off-diagonal 项**主动惩罚"用一个方向冒充多个方向"**——这正是"16 个 query 高度冗余（单 token R²=0.62，全 16 个只有 0.645）"的病。**冗余是 off-diagonal 项的定义域**。
- **我预测这是本 graft point 里 ROI 最高的一项**：改动 ~25 行、不重跑 Stage I、有三份成熟公开代码、且它攻击的是用户**已经量化确认**的两个病（秩 18 + query 冗余），而不是像候选一那样攻击一个**尚未确认**的病（随机性）。
- **风险**：白化在小 batch 下不稳（协方差估计噪声大）。WoG 用 `repeated_diffusion_steps=4` 复制 batch，但 O^c 在 4 份复制里是**同一个值**，所以**去相关统计必须在复制前的原始 B 上算**，否则有效样本数是假的。这是实现时最容易踩的坑。

# 候选三：**关系型 / 结构型对齐**（RKD、Correlation Congruence、VideoREPA-TRD、Procrustes/Gram）

用户点名的这一族确实有明确文献，而且**有一篇明确说"cosine 硬对齐在 finetune 场景会把已有表征打坏，应改成软的关系对齐"** —— 这与 WoG Stage II 的处境（backbone 已预训练、Stage I 已定 O^c，现在要 finetune）**结构同构**。

### 3a. VideoREPA / TRD loss — 最贴 WoG 的批评 + 现成损失

| 项 | 值 |
|---|---|
| arXiv | **2505.23656** |
| URL | https://arxiv.org/abs/2505.23656 |
| 提交 | **2025-05-29** |
| Comments 场 | **(none)** |
| 代码 | **https://github.com/aHapBean/VideoREPA**（从项目页 videorepa.github.io 取得，HTTP 200 已验证） |

**它对 cosine 的批评（我从 HTML §3.3 抄的原文）**：
> "**Mechanism Mismatch (Hard Alignment vs. Finetuning Stability)**: REPA employs a direct feature similarity loss (e.g., cosine similarity) to train a DiT **from scratch**. When applied during finetuning, this "**hard**" alignment objective attempts to **force potentially incompatible feature spaces** … to match directly. As demonstrated in our experiments, finetuning CogVideoX with standard REPA **leads to significant degradation in semantic quality and overall coherence**."

消融结论原文：*"REPA, with its 'hard' alignment approach (i.e., token similarity), is unsuitable for finetuning pre-trained VDMs as it can disrupt their established feature spaces. In contrast, our proposed TRD loss, which offers 'soft' guidance, proves substantially more effective."*

**TRD 损失（我抄的 Eq. 3-5）**：不匹配绝对向量，匹配**成对余弦相似度矩阵的 L1 距离**：
$$y^{d,i,j}_{\text{spatial}} = \frac{y^{d,i}\cdot y^{d,j}}{\|y^{d,i}\|\|y^{d,j}\|},\qquad \mathcal{L}_{\text{TRD}} = \tfrac{1}{f(hw)^2}\sum_{d}\sum_{i,j}\big|h^{d,i,j}_{\text{spatial}} - y^{d,i,j}_{\text{spatial}}\big| + (\text{temporal 项})$$

### 3b. RKD / Correlation Congruence — 经典出处

- **RKD**: arXiv **1904.05068**，*Relational Knowledge Distillation*，提交 **2019-04-10**(v1)/v2 2019-05-01，Comments 场 = **"Accepted to CVPR 2019"**，代码 **https://github.com/lenscloth/RKD**（HTTP 200 已验证）。机制：distance-wise（匹配样本对的归一化距离，Huber）+ angle-wise（匹配三元组夹角余弦）。
- **Correlation Congruence**: arXiv **1904.01802**，提交 **2019-04-03**，Comments 场 = **(none)**（**是 CVPR 2019 论文，但 abs 页没写；按纪律记为 (none)**），代码：未找到官方仓库；`HobbitLong/RepDistiller`（HTTP 200 已验证）内含 CC/RKD/PKT/CRD 等多种统一实现，**这是我推荐的抄代码来源**。

### 3c. Procrustes / Gram — 有理论说 CKA 和 projected-MSE 都不够

| 项 | 值 |
|---|---|
| arXiv | **2509.25253** |
| URL | https://arxiv.org/abs/2509.25253 |
| 标题 | *Knowledge distillation through geometry-aware representational alignment* |
| 提交 | **2025-09-27** |
| Comments 场 | **(none)** |
| 代码 | **未找到**（abs 页无 github） |

**这篇直接回答了用户列表里的 CKA 一项，而且答案是否定的**。摘要原文：
> "we **theoretically show that existing feature distillation methods, such as projection based mean squared loss or Centered Kernel Alignment (CKA), cannot capture the feature structure, even under zero loss**. We then motivate the use of **Procrustes distance** and the **Frobenius norm of Feature Gram Matrix** … up to 2 percentage points [improvement]."

**→ 这是我不建议 WoG 去做 CKA 的证据。** 用户 brief 里把 CKA 列为候选，但有论文论证 CKA 零损失时仍不能确定特征结构。若要走"结构匹配"路线，应直接上 Gram-Frobenius 或 Procrustes（且这两个实现比 CKA 还简单）。

### 如何嫁接（约 15-25 行，只重跑 Stage II）

WoG 只有 16 个 token，**Gram 矩阵是 16×16，成本可忽略**：

```python
a = F.normalize(obs_pre, dim=-1)                        # [B,16,32]
b = F.normalize(future_patch_features.detach(), dim=-1)
Ga = a @ a.transpose(1,2)                               # [B,16,16]
Gb = b @ b.transpose(1,2)
obs_loss = (Ga - Gb).abs().mean()                       # TRD 的 L1 形式
# 或 Gram-Frobenius: obs_loss = (Ga-Gb).pow(2).mean()
```
可与原 cosine 相加（软+硬混合），也可完全替换。

### 诊断预测（用数字论证）

- **对"秩 18"是间接命中**：Gram 矩阵是 16×16，秩至多 16，**天然只表达 16 个 token 之间的关系而不表达 512 个坐标**。它把优化目标从"匹配 512 个数"降到"匹配 120 个独立的成对关系"——**自动做了维度削减，但削减方式是数据驱动的，不需要手选 k**。
- **对"query 冗余"是正面命中**：单 token R²=0.62、16 token 只有 0.645 意味着 **16 个 token 的 Gram 矩阵接近全 1 矩阵**（互相高度相似）。TRD/Gram 损失会直接把这个"矩阵有多接近全 1"作为被监督的量。**如果 O^c 真实 Gram 有结构而 O^c_hat 的 Gram 是全 1，当前 cosine 损失完全看不见这个差异**（每个 token 各自对齐得挺好，但彼此关系全丢）。这是关系型损失相对 cosine 的唯一质变。
- **我预测这一项的效果排第二（在候选二之后）**，理由：它修的是"关系"而非"方向权重"。用户诊断说 top-8 方向占 97.7% —— 这是**坐标轴的问题**，白化（候选二）是对症的；Gram 是**token 轴的问题**，query 冗余是对症的。两个病都真实存在，但**97.7% 这个数字比 0.62-vs-0.645 更极端**，所以坐标轴优先。
- **候选二和候选三可以叠加且不冲突**（一个在 32 维坐标轴上去相关，一个在 16 个 token 上匹配关系），我建议作为一个组合实验跑。

# 候选四：只对齐"重要子空间"/ 残差 —— **我建议不要按直觉做，有反证**

用户 brief 提出"把 target 投到 top-k 主方向"或"按因果重要性加权"。我认真找了文献，结论是**混合的，而且有一条明确反证**：

**反证（来自候选一的 VFMF §4.2，我已抄原文）**：*"low-rank PCA … incurs noticeable information loss … PCA performs significantly worse than VAE on downstream dense prediction tasks"*；且 *"high-rank PCA preserves fine-grained details but **reintroduces geometry artifacts**"*。即**PCA 截断在两端都不好**：截得狠丢信息，截得松丢生成质量。既然这是同一篇论文在**同一种"预测冻结视觉特征"任务**上的实测，我认为它对 WoG 有直接参考价值。

**唯一找到的正面文献**：

| 项 | 值 |
|---|---|
| arXiv | **2307.16419** |
| URL | https://arxiv.org/abs/2307.16419 |
| 标题 | *Subspace Distillation for Continual Learning* |
| 提交 | **2023-07-31** (v1), v2 2023-08-01 |
| Comments 场 | **"Neural Networks (submitted May 2022, accepted July 2023)"** → venue **Neural Networks 期刊** |

机制：用**一阶线性子空间**近似数据流形，蒸馏子空间而非向量；论文声称对噪声鲁棒。但这是 continual-learning 场景（防遗忘），**与 WoG 的"privileged→non-privileged"不同构**，迁移是我的推断而非论文声明。

**我搜索的空缺（明确报告为未找到）**：`"important directions"+distillation`（2 条，均不相关）、`spectral+distillation+eigen`（0）、`Fisher+distillation+weighted`（0）、`"task-relevant subspace"+alignment`（1 条，不相关）、`"top-k"+principal+projection+loss+target`（0）、`eigenvalue-weighted / spectrum-weighted`（0）。**"用 top-k 主方向或因果重要性加权蒸馏损失"这个具体做法，我没有找到任何直接文献支撑。**

### 如果仍要做，最便宜的形式（约 15 行）

不做显式 PCA（避免 VFMF 指出的截断陷阱），而是**用固定的 per-dim 标准差做逆方差加权** —— 数学上是"白化的对角近似"，等于候选二的退化版：
```python
# 训练前一次性统计并冻结
oc_std = ...  # [32], 在训练集上算
w = 1.0 / (oc_std + 1e-3)                  # 低方差方向被放大 = 反向于 top-8 主导
obs_loss = (((obs_pre - target) * w) ** 2).mean()
```

### 诊断预测

- **注意这里有个方向性陷阱，我认为是用户 brief 里最容易搞错的一点**：诊断说 top-8 方向占 **动作相关信号** 的 97.7%。逆方差加权（上式）**放大低方差方向**，方向恰好**相反**——它会让 oformer 更努力去拟合那 494 个噪声方向。
- **正确的"重要性加权"应该用因果重要性，不是方差**。用户手上已有算这个的工具（他们测出了"O^c 对 Stage-I DiT 的因果效应 96%-108% 归因于 future-only 分量"）。可行做法：用 Stage-I 冻结 DiT 对 O^c 的**梯度范数**逐维估重要性 $w_j = \|\partial \mathcal{L}_{\text{act}} / \partial O^c_j\|$，冻结后作为损失权重。**这是 gradient/attribution-weighted distillation 的思路，但我要明确说：我没有为这个具体构造找到论文。属于 UNVERIFIED，是我基于用户诊断能力提出的方案。**
- **总体判断：本候选是"看起来最对症、但证据最薄"的一项。** 秩 18 / 97.7% 强烈暗示应该做子空间加权，但（a）唯一可引的论文是 continual learning、无可用代码；（b）同任务的 VFMF 实测反对 PCA 截断；（c）候选二的白化**在不做任何硬截断的前提下达到了同样的"重新分配方向权重"效果**，且有三份 ICML/ICLR 论文 + 三份公开代码。**我建议用候选二替代本候选，把它降为备选。**
