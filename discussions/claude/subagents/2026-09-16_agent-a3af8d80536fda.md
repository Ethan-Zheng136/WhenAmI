**Conditional CKA** appears most prominently in work on conditional/contextual independence testing and representation analysis. Centered Kernel Alignment (CKA) itself is a widely used similarity index for comparing neural network representations, introduced by Kornblith et al. (2019), which measures similarity between representations via normalized Hilbert-Schmidt Independence Criterion (HSIC) values.

Key threads in the literature:

**1. Conditional variants.** Extensions that condition on a third variable (e.g., class labels, input attributes, or nuisance factors) build on the *conditional HSIC* / conditional independence criteria of Fukumizu et al., replacing the plain HSIC numerator in CKA with a conditional cross-covariance operator. The motivation is that raw CKA can be dominated by shared dependence on labels or low-level input statistics, so two networks can look similar merely because both encode the class structure.

**2. Partial CKA / partialling-out.** Analogous to partial correlation, "partial CKA" refers to regressing out a known factor (a baseline representation, layer depth, or a confounding kernel) before measuring alignment. This is related to *partial distance correlation*, which has been used for exactly this purpose in representation comparison — most notably in work applying partial distance correlation to compare vision model embeddings while controlling for a third model.

**3. Known criticisms motivating these variants.** Several papers have shown standard CKA is sensitive to outliers and dominated by a few high-variance principal components, and that CKA scores can be manipulated while leaving functional behavior unchanged — which is a direct argument for conditioning or partialling out dominant shared structure.

Here's what I found on partial correlation approaches in RSA:

## Core idea

Partial RSA addresses a common confound problem: when two candidate model RDMs (representational dissimilarity matrices) are themselves correlated with each other, a raw correlation between a brain RDM and Model A may be driven entirely by Model A's shared variance with Model B. Computing the partial correlation between the neural RDM and Model A while controlling for Model B isolates the unique explanatory contribution of A.

## Typical implementation

- **Vectorize** the lower triangle of each RDM (neural, model-of-interest, and nuisance/control RDM).
- **Compute partial Spearman or Kendall's τ-a correlation** of the neural vector with the target model vector, residualizing out the control vector. Kendall's τ-a is often recommended by Nili et al. (2014, *PLoS Comp Biol*, the RSA toolbox paper) when candidate models predict tied dissimilarities.
- **Inference via randomization**: because RDM entries are not independent, significance is assessed with condition-label permutation tests (shuffling the stimulus labels of the neural RDM, ~10,000 permutations) rather than parametric p-values, and bootstrapping over stimuli for confidence intervals.

## Common use cases

- Separating **semantic from visual/low-level** similarity structure (e.g., controlling for pixelwise or Gabor-filter RDMs when testing category models).
- Separating **task/behavioral** structure from **stimulus** structure.
- Controlling for **temporal/sequence** or **run-order** confounds in MEG/EEG time-resolved RSA.
- Disentangling correlated **DNN layer** RDMs from one another.

## The closest existing thing: dCKA (deconfounded CKA)

### Deconfounded Representation Similarity for Comparison of Neural Networks
- **arXiv:** 2202.00095 — https://arxiv.org/abs/2202.00095
- **Date:** 2022-01-31
- **Authors:** Tianyu Cui, Yogesh Kumar, Pekka Marttinen, Samuel Kaski (Aalto University / Univ. of Manchester)
- **Venue:** NeurIPS 2022 (pp. 19138–19151). arXiv Comments field: **NONE** (no comment string on the abs page)
- **Status: VERIFIED** — title string exactly `Deconfounded Representation Similarity for Comparison of Neural Networks`
- **(a) Linear or nonlinear?** **Linear.** It residualizes via linear regression of the representation similarity matrix on the input similarity matrix. The paper explicitly says nonlinear variants were tested but linear was preferred for efficiency.
- **(b) Conditions on a third variable?** **Yes — this is exactly a partial-correlation-style construction.** It regresses out the *input* similarity structure (the confounder) from the representation similarity structure, yielding **dCKA** and **dRSA**. An eigenvalue correction is applied because subtraction can break positive semi-definiteness.
- **Caveat for your purposes:** the "third variable" is hardwired to the **input kernel** as a confounder. It is not presented as a general-purpose `CKA(X, Y | Z)` operator for arbitrary Z, and it is not called "conditional CKA" or "partial CKA."

This is the single closest existing thing to what you are describing, and it is the natural citation anchor.

## Summary of the gap

There is a genuine, citable hole here:

1. **The name is free.** "Conditional CKA" and "partial CKA" return literally zero defined-measure hits. The long forms return zero results at all in Google Scholar.
2. **The closest measure, dCKA (Cui et al., NeurIPS 2022), is linear and hardwires Z = input kernel.** It does not generalize to arbitrary Z and is not framed as a conditional operator.
3. **The closest arbitrary-Z construction, partial distance correlation (Zhen et al., ECCV 2022 best paper), is nonlinear but is not CKA** — it is distance correlation, with different invariances and no kernel-alignment normalization.
4. **The formal kernel conditional machinery exists (HSCIC, KCI-test) but was never normalized into a CKA-style bounded similarity index.** HSIC → CKA is a normalization step; the analogous HSCIC → "conditional CKA" normalization has apparently not been published.
5. **"Partial RSA" is the established terminology precedent** and, given the known RSA–CKA equivalence results, is the most natural thing to point at when arguing a partial CKA is well-posed.

If you define such a measure, the honest framing is: *no named conditional/partial CKA exists; the closest are dCKA (linear, input-kernel-only) and partial distance correlation (nonlinear, not CKA); HSCIC provides the conditional kernel operator but has never been normalized into a CKA-style index; and "partial RSA" establishes the precedent in the sibling RSA literature.*
