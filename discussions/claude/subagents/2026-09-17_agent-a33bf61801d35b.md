## 改动 1：给 condition encoder 加「预测未来动作」辅助头

### 判决：**(a) 已被做过** —— 而且是多次、多路径地做过

**决定性证据 1：ForeTime-VLA** — [2608.20735](https://arxiv.org/abs/2608.20735)，2026-08-21 (v2 08-24)，Comments: "8 pages, 5 figures"（纯 preprint，无 venue），代码未公开。

我读了 HTML 全文。它的结构与你的改动 1 **是同一件事**：
- 特权 teacher encoder 吃 `(current feat, future feat, 26-D state)` → 64-D code（等价于你的 `O^c`）
- **一个 shared action decoder 从这个 code 重建 normalized action chunk**（= 你的轻量动作头）
- 五项监督里显式列出 **"auxiliary action reconstruction"**
- 连你的动机都被独立发现了：他们发现初始 code "exhibit**ed** insufficient variation"（= 你的"只编码任务进度"），并用 VICReg 式 variance/covariance 项去解决

更扎心的是：它还**额外**把"任务进度"显式拆出来做成独立的 time-to-transition 头 + phase 头（用 gripper-state transitions 定义 phase）。也就是说，"`O^c` 里的进度信号应该被分离出去、动作信号应该被显式监督"这套完整论证，已经被写过。

**决定性证据 2：villa-X** — [2507.23682](https://arxiv.org/abs/2507.23682)，2025-07-31 (v3 09-25)，**ICLR 2026 Poster**（已核实，iclr.cc/virtual/2026/poster/10006594），**代码公开** github.com/microsoft/villa-x，Microsoft Research + 清华 + HKUST 等。

它的 proprio-FDM 是你的 gripper 动机的**逐字前身**。原文：

> "certain motions, such as end-effector rotations or **gripper movements, are subtle in pixel changes but critical for control**" → 因此加 "a proprioceptive Forward Dynamics Model (proprio FDM) as an **auxiliary decoder**" 预测 "future robot states **and actions**"

这就是你写的"要求它能预测 gripper 开合序列可以强迫它编码具体动作"。且有消融（w/pp vs wo/pp）证明有效。

**决定性证据 3：Delta-JEPA** — [2606.31232](https://arxiv.org/abs/2606.31232)，2026-06-30，cs.AI，无 venue，代码未公开。

你怀疑得对。它的 multi-step LDAD **就是从 world-model latent 上挂一个多步动作解码头**：用 Transformer + **learnable action queries**，通过 AdaLN 注入 latent displacement，解码 `[t, t+H]` 的连续动作序列，MSE loss。这与你"从 `O^c` 加轻量头预测未来 16 步动作"在架构层面几乎同构。它还做了你会想做的消融（decoding target: raw action vs 各种 state-delta proxy — 结论是 raw action 最好）。

**你点名的另两篇，威胁较小但不为零**：
- **SelfWAM** [2608.00725](https://arxiv.org/abs/2608.00725)（2026-08-01，上科大，Comments 空，代码未公开）：方向**相反** — 它把 clean GT 动作注入未来编码器（action → encoder），你是从 encoder 预测动作（encoder → action）。但它的**摘要第一句就是你的动机**："conditioning future prediction only on the task prompt and observation context risks capturing **generic task progression** rather than the **action-specific consequences**"。你的 motivation 段落已经无法作为新观察来写。
- **Seer** [2412.15109](https://arxiv.org/abs/2412.15109)（2024-12-19，上海AI Lab/北大/港中文，代码公开）、**GR-1** [2312.13139](https://arxiv.org/abs/2312.13139)（2023-12-20，ByteDance）：都是 predict-future-then-IDM，属于 inverse dynamics 大类的经典前身，不直接撞你的"辅助头"，但坐实了这条路是红海。[WAM Survey 2606.20781](https://arxiv.org/abs/2606.20781) 把"从 future representation 解码动作"列为整个领域的主干设计轴之一。

### 你还剩什么

只剩一个**实证观察**，不是方法：WoG 原文（我读了全文）**没有做任何 probing 分析** — 没有 tstep probe、没有 R²、没有讨论 `O^c` 编码了什么。你的 **R²=0.934** 是你自己的发现。但 ForeTime-VLA 已经独立发现了同一个病并给了药，SelfWAM 已经在摘要里陈述了同一个诊断。

🟡 **FLARE** [2505.15659](https://arxiv.org/abs/2505.15659)（NVIDIA+UMD，2025-05-21，无 venue）：32 个 learnable query 的 QFormer，有一节就叫 "**Action-aware** Future Embedding Model"。同词汇、同架构 — 审稿人最可能拿它质疑你。必须一句话划清（它的 "action-aware" 指端到端 flow loss，嵌入不以 x_t 为输入、每观测只算一次）。

**两个你必须修正的技术错误：**
1. **50% + stop-grad + double forward 是 Analog Bits ([2208.04202](https://arxiv.org/abs/2208.04202)，Chen/Zhang/**Hinton**，ICLR 2023) 的配方，不是 RIN 的。** RIN ([2212.11972](https://arxiv.org/abs/2212.11972)，ICML 2023) 默认自条件化率是 **0.9**，且 RIN 传的是**隐藏 latent**、Analog Bits 传的是 **x̂₀** — RIN 原文明确划界："*While these works condition on predictions of data, latent self-conditioning conditions a network on its own hidden activations*"。
2. **传 x_t 可能无信息增量** — x_t 在去噪器侧已经是输入，条件编码器再看一遍是冗余。**应该注入 x̂₀ 或中间 latent**。这是实质设计问题，不是措辞问题。

**要让它站得住必须补**：(1) **go/no-go 实验** — 先复现 UD-VLA 的负结果（朴素拼接），再加 dropout+stop-grad 看是否翻正，翻不正就死；(2) 对照"同等算力给更多去噪步/更大动作头"；(3) x_t vs x̂₀ vs latent 三种注入物对比；(4) dropout rate 当超参扫，别硬套 50%。

三处被封死：

1. **动机"null 分支欠训练/OOD 有害"已被说尽**：[Autoguidance 2406.02507](https://arxiv.org/abs/2406.02507)（NVIDIA, Karras 等，**NeurIPS 2024**）原文已写"unconditional and conditional denoisers are trained to solve **a different task**"、"typically only **a small slice of the training budget**"，并给出量化证据 EDM2-S: FID **2.56 条件 vs 11.67 无条件**。同族还有 [CFG++ 2406.08070](https://arxiv.org/abs/2406.08070)、[TCFG 2503.18137](https://arxiv.org/abs/2503.18137)（CVPR 2025）、[CADS 2310.17347](https://arxiv.org/abs/2310.17347)（ICLR 2024）、[PAG 2403.17377](https://arxiv.org/abs/2403.17377)（ECCV 2024）、[SAG 2210.00939](https://arxiv.org/abs/2210.00939)（ICCV 2023）。

2. **方法已被更彻底地做过**：[ICG 2407.02687](https://arxiv.org/abs/2407.02687)（"No Training, No Problem: Rethinking CFG"，ETH+Disney，**ICLR 2025**）原文明确写了 scale matching："*a Gaussian distribution **with a suitable standard deviation so that ŷ matches the scale of the actual conditioning vector y***"，以及用 "**a random condition from the conditioning space**... as it stays closer to the conditioning distribution"。他们**干脆不要 null token**。你的方案是它的**更弱版本**，审稿人必问"为什么不直接用 ICG"。

3. **"均值初始化新嵌入"在 NLP 是库默认行为**：HuggingFace `transformers` 的 `modeling_utils.py` 里 `mean_resizing: bool = True` 是**默认开启**的，注释理由与你一字不差。相关研究：[2608.03494](https://arxiv.org/abs/2608.03494)（系统比较，指出均值法**需配合 norm rescaling**）、[2604.02324](https://arxiv.org/abs/2604.02324)（**反面证据**：均值初始化会让新 token 塌缩到退化子空间）。

**两个技术性反驳（比新颖性更致命）：**

- **数学上"均值 ≠ 边缘化"**：CFG 无条件分支要近似的是 `∇log E_c[p(x|c)]`，即 **score 在 c 上的期望**；你喂的是**期望的 c**。网络对条件非线性，存在 Jensen gap。ICG 正是意识到这点才选择**采样**随机条件（无偏）而非取均值（有偏）。所以"均值 = 真正的平均条件基线"**在数学上是错的**。
- **高维下均值不在流形上**（4096 维数值模拟）：真实样本范数 ~69.9，**均值向量范数只有 19.2（27.5%）**，且均值到任意真实样本的距离（67）与样本间距离（95）同量级。裸均值方向变了但"范数不对"这个病没治好。

**唯一站得住的技术点**：WoG/CogACT 的 `uncondition` 是独立 `nn.Parameter` 活在 4096 维 VLM 特征空间，`std=0.02` 使其范数 ~1.28 vs 真实条件 ~70 — **差 50 倍，确实病态**。（注意：DiT 原版 null token 与真实类别嵌入**共用同一张 embedding 表和同一初始化**，本来就同分布，不存在此问题。这是 CogACT 的实现瑕疵，不是 CFG 的普遍问题。）

**还有初始化冲刷问题**：`uncondition` 每步以 10% 概率拿稠密梯度，几十万步后几乎必然漂离初值。[1711.09160](https://arxiv.org/abs/1711.09160)（ICON 2017）结论：只要方差合理，各种初始化最终收敛到相近性能。

**处置建议**：放进 ablation 表一行（`N(0,0.02)` vs mean vs **mean+cov**），**不进标题/摘要/独立小节**。若有提升，如实写成"修复了 4096 维空间的 scale mismatch"这一实现问题，且正确做法是 **mean+covariance**（对齐 HF `mean_resizing`）或 scale-matched，而非裸均值。
