# VLA 中"未来预测作为辅助训练目标"文献综述

**核查日期 2026-09-15。** 全部 arXiv 元数据（v1/最新版本日期、COMMENTS 字段）经 `curl https://arxiv.org/abs/<id>` 一手取得；录用状态经 `api2.openreview.net` 一手确认（注：v1 API 已废弃）；star 数为 GitHub API 实时值。**关键方法论警示：arXiv COMMENTS 字段严重不可靠**，本次发现 ≥5 例"arXiv 无录用标注但实为已录用"（RoboDreamer、DreamGen、Gen2Act、UniVLA-BAAI、Genie Envisioner）。

## 核心结论先行：这条线的四种范式

我建议用**「推理时预测通路还剩多少」**而非「有没有 world model」来切分：

| 范式 | 定义 | 代表 |
|---|---|---|
| **A. 纯辅助（decoder 完全丢弃）** | 预测头训练时用、推理时删 | **DreamVLA**、**FLARE**、**GR00T N1.5**、Seer、GR-1/GR-2、UniVLA-BAAI |
| **B. 单步 latent 前向（跑但不解码像素）** | 预测网络在推理时前向一次，只取中间特征 | **VPP**、**GE-Act**、**MinD**、**DiT4DiT**、BagelVLA |
| **C. 统一生成模型（同权重可切换）** | policy 模式跳过视觉分支，但生成器完整可用 | **UVA**、**WorldVLA**、**GigaBrain-0.5M\*** |
| **D. 真 rollout（分层规划器）** | 生成未来帧 → IDM 抽动作 | **UniPi**、**SuSIE**、**RoboDreamer**、**Vidar**、GE-Sim |

**最强的一手实证支撑（本次两大发现）**：
- **Fast-WAM**（arXiv 2603.16666，v1 2026-03-17）标题即为 *"Do World Action Models Need Test-time Future Imagination?"*，结论：保留 video co-training 但**推理时跳过未来预测**，性能与 imagine-then-execute 持平；**去掉 video co-training 掉分大得多**。延迟 190ms，快 4×。原文："the main value of video prediction in WAMs may lie in improving world representations **during training** rather than generating future observations at test time."
- **GigaBrain-0.5M\***（2602.12099）部署时有 **efficient mode（world model 完全 bypass）** 与 **standard mode（主动生成）** 两种可切换模式，靠训练期 stochastic masking 实现。
