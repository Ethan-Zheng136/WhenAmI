### 4.1 三篇指定必读

**2605.20223** `Why Latent Actions Fail, and How to Prevent It`
https://arxiv.org/abs/2605.20223 | 2026-05-13 | Lee Jung Min, Cho Taehyun, **Zhao Li (MSRA), Lee Jungwoo (SNU)** | COMMENTS 空（无 venue）| cs.CV

做了什么：把 linear LAM 框架扩展到显式建模 exogenous state，在 **Ex-BMDP**（Exogenous Block MDP）假设下做解析分析。两个结论：(1) 标准重建目标必然让 latent action 编码 **来自未来观测的 exogenous 信息**；(2) 在"聚焦 endogenous 成分的表示空间"里学习是关键解药。还证明了 action-supervision 类辅助目标可证明地鼓励 latent action 跨 exogenous state 一致。

全文核实（我 grep 了 HTML 全文）：
- L404 明确写出 Ex-BMDP 定义，`S` 是 "(minimal) endogenous states, which is the (minimal) information that is necessary to control the agents and **fully discards unnecessary information**"
- L438-439 关键假设：数据采集策略是 **endogenous policy**，即 `π(a|o) = π(a|s)`
- L1399-1443 的数学工具是 **正交投影 Π onto range(B*)**，把残差 `o' - A*o - B*z*` 沿 range(B*) 及其正交补分解

与本 idea 的精确差异（这是最危险的一篇，必须讲清）：
- **用的数学工具几乎一样**：正交投影 + 残差分解。表面看 "target* = O^c - Proj(O^c|z)" 就是它的 L1402。
- **但投影的对象根本不同**：它投影到 `range(B*)`（latent action 的生成矩阵的像空间），目的是把 **exogenous 噪声 ξ'** 从 latent 里挤出去。本 idea 投影到 **z（学生策略表示）的张成空间**，目的是把 **z 已知的部分** 从 teacher target 里挤出去。
- **划分标准是环境属性 vs 模型属性**：它的 endogenous/exogenous 是 Ex-BMDP 的**结构性、固定**划分（背景杂物永远是 exogenous，机械臂永远是 endogenous）。本 idea 的 "已知 / 残余" 是**相对于 z 的、训练中漂移**的划分——训练早期 z 弱，几乎全是残余；训练后期 z 强，残余收缩。前者是静态先验，后者是动态的自适应课程。
- **Crucially，它无法覆盖本 idea 的核心场景**：一个 **endogenous 且 control-relevant** 的特征（比如机械臂当前位姿），在它的框架里是"必须保留"的；但在本 idea 里，如果 z 从 O_t 已经完美知道机械臂位姿，这部分就该从 distillation target 里减掉——因为它贡献零梯度信息。它的理论**不会**减这一项。本 idea 减的恰恰是它要留的。
- 另一点：它是 **LAM**（latent action 作为 z），本 idea 是 **VLA policy representation** 作为 z，teacher 是 future-obs encoder。角色不同但确实构成"镜像问题"。

**2606.30068** `Predictive Objectives Discard Exogenous Control-Relevant Features: A Controlled Mechanistic Study`
https://arxiv.org/abs/2606.30068 | 2026-06-29 | **Pendharkar, Ayan（单作者）** | COMMENTS: 15 pages 3 tables 5 figures + github | cs.LG

做了什么：一个受控 2x2 实验设计（controllability × relevance 独立变化），配一个 "predictability knob" 把特征的时序可预测性与 control-relevance 解耦。对比 6 个目标（reconstruction / JEPA / action-conditioned JEPA / controllability-based JEPA / IDM under random policy / reward-grounded JEPA）。发现：**所有 reward-free 预测目标都把 "exogenous 但 control-relevant" 的特征丢到接近随机猜测的水平**；只有 reward-grounded 变体选择性保留。2% reward 标注即可恢复。跨 16-1024 latent 维度都成立；并与 bisimulation 理论的几何预测对比（JEPA latent 只实现了监督参考的一小部分类别分离）。

与本 idea 的精确差异：
- **这篇是本 idea 的最强"反向盟友"，不是竞争者**。它证明的是"预测性目标**扔掉了**该留的东西"（exogenous but control-relevant 被丢）。本 idea 说的是"预测性目标**留了**不该留的东西"（z 已知的冗余）。两者都是"预测目标与 control-relevance 不对齐"这个大命题下的**互补两半**。
- **它甚至可以被引为本 idea 的动机支撑**：它明确说 "the objective optimizes temporal predictability rather than control-relevance"。本 idea 的 "keep only residual **still necessary for action**" 正是在补这个 control-relevance 约束。
- **它没有提出任何减法机制**。它的解药是 **reward grounding**（加 2% reward 标注），而不是从 target 里减去任何东西。没有投影、没有 conditional MI、没有正交惩罚。
- 但要诚实：它已经把 **"per-latent-dimension 上做受控消融 + 用 probe accuracy 度量特征是否被保留 + 扫 16→1024 维"** 这套实验范式做掉了。这对 **Q6** 有部分抢占（见 6.4）。
- 注意其分量：单作者、15 页、无 venue、无机构署名。理论深度有限，是实验性 position paper。

**2505.17006** `CoMo: Learning Continuous Latent Motion from Internet Videos for Scalable Robot Learning`
https://arxiv.org/abs/2505.17006 | 2025-05-22 | Yang Jiange, Shi Yansong, Zhu Haoyi, Liu Mingyu（**南大 / 上海AI Lab / 浙大**）| **COMMENTS: CVPR 2026** | cs.CV, cs.RO

做了什么：early **temporal difference (Td)** 机制 + **temporal contrastive learning (Tcl)**。Td 提高 shortcut learning 的难度、显式增强 motion cue；Tcl 的正样本是小时序偏移的未来帧、负样本是**直接反转时间方向**。目标是让 latent motion 聚焦前景而非静态背景。

与本 idea 的精确差异：
- **Td 就是最朴素版本的"减去当前帧"** —— 而这恰恰是本 idea 在括号里**明确排除**的那件事（"crucially: NOT merely subtract current-frame features"）。所以 CoMo 是本 idea 的**对照组 / 弱基线**，不是抢占。
- 差异的本质：`O_{t+k} - O_t` 是**固定的、无参数的、像素/特征级**的差分；`O^c - Proj(O^c|z)` 是**学习的、参数化的、依赖策略表示**的投影。前者减的是"当前帧"，后者减的是"z 能预测的任何东西（包括 z 从 O_t 推断出的未来）"。关键区别：一个好的 z 能预测的远多于 O_t 本身——比如 z 知道任务语义、知道抓取阶段，因此能预测未来帧里的大部分结构，这部分 Td 减不掉。
- CoMo 完全没有信息论框架，没有 minimality / sufficiency / conditional MI 的讨论。纯经验性的架构技巧。

**这条线是否等于"减去非 control-relevant"？是的，字面上完全是。** 它们形式化的就是：状态空间分解为 `X = S × Ξ`，只保留 S，**完全丢弃** Ξ。

**但与本 idea 是否同一件事？不是，有三层根本差异：**
1. **划分的定义源**：Exo-MDP 的 S/Ξ 划分由**环境的因果结构**决定（Ξ 的转移不受 action 影响），是一个**客观、与学习者无关**的事实。本 idea 的"已知/残余"划分由**学生表示 z 当前的能力**决定，是**主观、随训练演化**的。
2. **被减掉的东西的性质**：Exo-MDP 减掉的是 **control-irrelevant** 的（对 action 无用）。本 idea 减掉的是 **control-relevant 但已冗余** 的（对 action 有用，但 z 已经有了，所以作为 distillation target 无信息增益）。**这是完全不相交的两个集合。** Exo-MDP 的框架里，"z 已知的 endogenous 状态"是**必须保留**的核心；本 idea 要减掉它。
3. **对"minimal sufficient"的用法**：Exo-MDP 是 `I(S; 未来控制) ` 意义下的最小充分，无条件。本 idea 是 **conditional** minimal sufficient：`I(target; action | z)` 最大化同时 `I(target; z)` 最小化。**Exo-MDP 线从未写下以学生表示为条件的 CMI 目标。**

### 4.5 Q4 关键机制论证（为什么"减 exogenous" ≠ "减 z 已知"）

必须把这点钉死，否则 reviewer 会说"你就是 2605.20223 换个说法"：

设 `O^c` 为 teacher 编码的未来目标。三分解：
- **A = exogenous 部分**（背景晃动、光照）：control-irrelevant。全线 LAM 工作（2605.20223 / 2602.02259 / 2607.09185 / 2502.00379 / Ex-MDP）都在减这个。
- **B = endogenous 且 z 已知**（当前机械臂位姿、已抓住的物体身份、任务阶段）：**control-relevant 且 z 已有**。→ **本 idea 独家要减的就是 B。整条 exogenous 线明确要保留 B。**
- **C = endogenous 且 z 未知**（未来接触事件、被遮挡物体将露出的构型）：这是真正的学习信号。所有人都要留 C。

于是：exogenous 线的 target 是 `B + C`；CoMo/RLA/Mantis 的 target 约为 `A_residual + C`（减当前帧顺手减掉部分 A 和部分 B，但不精确，且减不掉 z 从 O_t **推断**出的 B）；本 idea 的 target 是 **`C` alone**。**三者互不相同，且本 idea 的 C 最小。**

并且 2606.30068 提供了一个警告：**过度减法可能把 "exogenous but control-relevant" 的特征也减掉**。本 idea 的 "keep only residual still necessary for action" 这个 sufficiency 约束正是防这个的——**但这意味着本 idea 必须实现双约束（minimality + action-sufficiency），单纯做 `O^c - Proj(O^c|z)` 会踩 2606.30068 的坑**。这是个必须在方法设计里正面处理的技术风险。

### 6.1 PID → 知识蒸馏（最强抢占，必须引）

**2411.07483** `Quantifying Knowledge Distillation Using Partial Information Decomposition`
https://arxiv.org/abs/2411.07483 | 2024-11-12 | Dissanayake Pasan, Hamman Faisal, Halder Barproda, **Sucholutsky Ilia** (+ Dutta 组, **Univ. of Maryland / NYU / Princeton 系**) | **COMMENTS: Accepted at AISTATS 2025** | stat.ML, cs.CV, cs.IT, cs.LG

做了什么：问"知识蒸馏的信息论极限是什么"。用 PID 量化 **transferred knowledge** 与 **knowledge left to distill**。**理论证明：task-relevant transferred knowledge 恰好等于 teacher 与 student 之间关于 task 的 redundant information** `R(T; teacher, student)`。据此提出 **Redundant Information Distillation (RID)** —— 一个 multi-level optimization，把 redundant information 作为 regularizer。明确动机：**"the teacher's representations can also encode nuisance or additional information not relevant to the downstream task. Distilling such irrelevant information can actually impede the performance of a capacity-limited student model."**

与本 idea 的关系（**这是整个 Q6 最需要正面处理的一篇**）：
- **同向**：都认定"teacher target 里有不该蒸的部分"，都用信息论分解来刻画，都把它变成一个 regularizer。动机句几乎可以直接搬到本 idea 的 intro。
- **精确差异（三点，都是实质性的）**：
  1. **减的方向相反**。RID **最大化** redundancy `R(task; teacher, student)`（因为它认为 teacher∩student 关于 task 的共识才是可靠知识，要留）。本 idea 要**最小化** `I(target; z)`（teacher 与 student 的重叠是浪费，要减）。**表面上完全对立。** 这个必须解释清楚，否则被 reviewer 一击致命。解释在于：RID 的 redundancy 是**训练后度量 student 学到了多少**的诊断量（"已成功转移的知识"），而本 idea 的重叠是**训练中 target 构造时**的冗余（"不需要再转移的知识"）。前者是 outcome，后者是 input design。**但这个区分微妙，需要极其小心的论述。**
  2. **RID 里没有"未来观测"和"当前观测已知"这个结构**。它是静态分类任务（CIFAR/ImageNet 类），没有时序、没有 `z 已见 O_t` 这个具体的冗余来源。本 idea 的冗余有明确的**时序因果来源**（O_t ⊂ O_{t+k} 的信息）。
  3. **RID 不做 per-dimension 分析**。它是全局的 PID 标量量。**没有 PCA、没有 per-dim causal ablation、没有"方向是否可从另一表示预测"的谱**。→ **Q6 的核心实验设计仍然空着。**
