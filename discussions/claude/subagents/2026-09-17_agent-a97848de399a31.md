## 背景（被查重的基线方法 WoG, arXiv 2602.22010）
两阶段 VLA。Stage I 用 QFormer 把**未来 5 帧的视觉特征**压成 16 个 query token `O^c`（[B,16,32]），作为 cross-attention 的 K/V 注入 DiT 动作专家的每一层。Stage II 冻结 qformer，用一个 oformer 从 VLM 的输出 token 预测 `O^c_hat`，损失是逐 token 余弦 `(1-cos).mean()`。

调研者的实测诊断：`O^c` 的方差 83% 可以被"当前帧版本的 O^c"线性重建（即大部分是静态内容，不是运动），但因果效应 96%-108% 来自"未来独有成分"。所以想让 `O^c` 只编码 **Δ（动作导致的未来变化）**。

## 你要查的三个改动（C 组）
- **C1 (delta target)**：future encoder 的 target 改成 `motion_td = future_feat − current_feat`（隐空间特征差分），当前帧作为 context 留在 condition 位。
- **C2 (time-reversal negative)**：用**时间反转的视频片段作为对比学习的负样本**来训练 future encoder。理由：静态内容在时间反转下不变，只有 Δ 翻符号，所以静态分量在数学上不可能承载这个判别任务。
- **C3 (LEACE concept erasure)**：用 LEACE（least-squares concept erasure，闭式线性擦除，Belrose et al. NeurIPS 2023, arXiv 2306.03819）把"当前帧可解释子空间"从 `O^c` 里擦掉，零训练的后处理。

## 一、结论先行

**C1 和 C2 都撞车了，而且撞在同一篇论文上：CoMo (2505.17006, CVPR 2026)。** 它的两个核心组件 Td（早期时序特征差分）和 Tcl（时间反转作负样本）逐条对应 C1 和 C2，连动机（抑制静态背景 shortcut）都一样。C3 是三个里唯一有实质空白的。

## 二、指定核实的五篇 [全部已核实，逐个 curl 过 abs 页]

**1. CoMo — arXiv 2505.17006** · https://arxiv.org/abs/2505.17006 · 2025-05 提交，v3 2026-06 · 南大 + 上海AI Lab（Jiange Yang, Tong He, Limin Wang 等）· **Comments: CVPR 2026** · abs 页无 github 链接

方法（从 html 全文核实，非仅摘要）：IDM 用共享的 MAE-pretrained ViT 抽 `F_t` 和 `F_{t+n}`，**逐元素相减得 token 级特征差分 `D_t`**，然后**显式把 `F_{t+n}` 从 encoder 输入里删掉**，只把 `F_t`（当前帧作 context）和 `D_t` 拼起来送进 encoder。Tcl 用 InfoNCE，正样本是小时序偏移 `(Z_{t,t+n+δ}, Z_{t,t+n})`，负样本是 `(Z_{t,t+n+δ}, Z_{t+n,t})` 和 `(Z_{t,t+n}, Z_{t+n,t})` —— `Z_{t+n,t}` 就是**把当前帧和未来帧调换顺序**送进 IDM 得到的时间反转表征，δ 取 `[-n/5, n/5]`。

**2. Delta-JEPA — arXiv 2606.31232** · https://arxiv.org/abs/2606.31232 · 2026-06-30 · 中科院大学等（Zhenghao Zhang 等，14 作者）· **Comments 无**（即无 venue，疑似纯 preprint）· 无代码

实际做法与 C1 **方向相反**：它的 LDAD（Latent Difference Action Decoder）是从相邻观测的**潜在位移中反解出已执行的动作**（displacement → action），是个 action reconstruction 正则项，目的是防止 JEPA 表征塌缩成动作不敏感。是 world model + 规划（4 个视觉连续控制任务），**不是 VLA 动作生成**，也不是把 delta 当 future encoder 的 target。对 C1 的威胁**低于预期** —— 真正的威胁是 CoMo，不是它。

**3. Mantis — arXiv 2511.16175** · https://arxiv.org/abs/2511.16175 · 2025-11，v2 2026-02 · 上交大（Zhijie Deng 组）· **Comments 无** · 代码称已释出但 abs 页无 github 链接

DVF：用 meta queries + DiT head 把视觉预见从 backbone 解耦，**当前视觉状态通过 residual connection 喂给 DiT**，于是简单的 next-state 预测目标让 meta queries 自动捕获「刻画视觉轨迹的 latent action」。注意：**这个 residual connection 在架构层面实现了和 C1 等价的效果** —— DiT 只需预测残差，meta query 自然只承载差分。这是 C1 的第二个撞击点，且发生在 VLA 内部。

**4. dWorldEval — arXiv 2604.22152** · https://arxiv.org/abs/2604.22152 · 2026-04-24 · Midea/美的（Yichen Zhu 等）· **Comments 无** · 无代码

Δ-LPIPS 精确定义（已从全文抄出）：固定 stride Δ，算差分图 `Δo_t = o_{t+Δ} − o_t`（预测同理），然后
`Δ-LPIPS = E_t[ d_lpips( norm(Δô_t), norm(Δo_t) ) ]`
论文自述动机是「Standard LPIPS captures only static appearance」。**确认是像素空间的评测指标，不是训练目标**，与 C1 不冲突，但它公开背书了「静态成分主导、必须看差分」这个 framing。

**5. LEACE — arXiv 2306.03819** · https://arxiv.org/abs/2306.03819 · 2023-06，v4 2025-04 · EleutherAI + ETH（Belrose, Ravfogel, Cotterell, Biderman）· **Comments 无**（但 NeurIPS 2023 已由 neurips.cc/proceedings 页独立确认）· **代码公开 github.com/EleutherAI/concept-erasure**

存在性确认。闭式最小二乘擦除：whiten → 投影到概念子空间正交补 → unwhiten，可证明阻止**所有线性分类器**探测该概念，同时以最小范数改动嵌入；配套 layer-wise「concept scrubbing」流程。原论文实验只在 LLM（POS 信息、BERT 性别偏见）。

## 四、三个判决

### C1 (delta target) — **(a) 已被做过。撞车，不粉饰。**

CoMo 的 Td 就是 C1：**隐空间特征差分作 encoder 输入 + 当前帧作 context 保留 + 显式删掉未来帧特征**，三个要素一个不差，连「防 shortcut / 抑制静态」的动机都一样。Mantis 的 DiT residual connection 是 C1 在 VLA 内部的第二次实现。DeltaTok 是 C1 在生成式 world model 上的第三次实现。

**唯一剩下的格子（很窄）**：CoMo/Mantis 的 delta 用在 **latent action / pseudo-label / 单步 next-state**；WoG 的 `O^c` 是 **16 个 query token 的多帧（5 帧）未来压缩条件，通过 cross-attention 注入 DiT 每一层，且有 Stage II 的 oformer 余弦预测**。「对 QFormer 压缩的多帧未来条件做 delta 化，并观察它对 Stage II 可预测性的影响」严格说没人做过。但这是**实现位置的差异，不是 idea 的差异** —— 审稿人会直接说 "this is CoMo's Td applied to a different architecture"。建议不要把 C1 当 contribution 卖，降级为一个 ablation 行。

### C2 (time-reversal negative) — **(a) 已被做过，而且在 VLA/机器人领域也做过。撞车。**

两层都被占了：
- **通用视频 SSL 层**：Shuffle&Learn (1603.08561) / O3N (1611.06646) / IIC (2008.02531) 2016-2020 就把「打乱或反转时序作判别任务/负样本」做透了。
- **机器人/latent action 层（这才是致命的）**：**CoMo (2505.17006, CVPR 2026)** 的 Tcl 和 **ConLA (2602.00557)** 都已经把「时间反转片段作对比负样本」用在从视频学运动表征上，且 ConLA 的论证一字不差就是 C2 的论证（「反转下内容不变、运动剧变」）。所以「有没有人把它用到 world model / robot policy 的 future encoder 上」这个关键空白判定的答案是：**有，至少两篇**。

C2 里那个漂亮的数学论证（「静态分量在时间反转下不变，因此数学上不可能承载该判别任务」）是正确的，但**不是新的** —— 它是 CoMo 和 ConLA 的公开动机陈述。

### C3 (LEACE concept erasure) — **(b) 别领域做过但没用于 VLA / 接近 (d)。这是三个里唯一能站住的。**

LEACE 本体 2023 年成熟且有官方实现，但**六年来的引用没有一篇进入机器人 / world model / VLA / 视觉条件表征**。机器人侧处理「静态污染 latent」的现有手段全是**训练时**的：VQ 瓶颈（LAPA）、特征差分（CoMo）、对比负样本（CoMo/ConLA）、mask 到 agent 像素（MaskLAM 2602.02259）、因果去偏微调（CD-LAM 2607.09185）、监督注入（LAOM 2502.00379）。

**空白具体在哪一格**：**「零训练的闭式后处理线性擦除」这一格完全空着。** 没有任何一篇机器人论文用投影/正交补的方式在**已训练好的条件表征上**做后处理。而且 C3 和调研者的实测诊断天然咬合 —— 「83% 方差可被当前帧版本 `O^c` 线性重建」正是 LEACE 所擦除的那类**线性可解释子空间**，这个诊断本身直接给出了 LEACE 的 concept 定义。

**但必须提醒两个风险**（诚实起见）：
1. LEACE 只保证**线性**不可探测。83% 线性可重建 → 擦完还剩非线性残留，且 DiT 的 cross-attention 是非线性的，可能仍能读出静态内容。
2. 更要命的是诊断本身：因果效应 **96%-108% 来自未来独有成分**，说明那 83% 的静态方差**本来就没在起作用**。擦掉一个已经不起作用的东西，很可能测不出增益。C3 的卖点应当是「零成本 + 可解释性诊断工具」，而不是「涨点」—— 如果按涨点写，大概率做出来是平的。

## 五、给调研者的直接建议

三个改动里，C1 和 C2 应当合并降级为「我们验证了 CoMo 的 Td/Tcl 迁移到 condition-space world modeling」的复现性 ablation，并在 related work 里**主动引用 CoMo 而不是回避** —— 这两条被审稿人查出来的概率接近 1（CoMo 是 CVPR 2026，可见度高）。真正值得投入的是 C3，但要把叙事从「提升成功率」改成「用闭式擦除做因果验证」，否则会被那个 96%-108% 的诊断反噬。
