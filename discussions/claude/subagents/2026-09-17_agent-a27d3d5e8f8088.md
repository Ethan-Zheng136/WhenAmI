## 四、一个你可能忽略的数学问题：均值 ≠ 边缘化

即使抛开新颖性，你的理论叙述本身有漏洞：

CFG 的无条件分支要近似的是**边缘分布** p(x) = ∫p(x|c)p(c)dc 的 score，即 **score 在 c 上的期望**；而你喂进去的是 **"期望的 c"**。由于网络对条件是非线性的：

∇log E_c[p(x|c)] ≠ E_c[∇log p(x|c)] ≠ f(E[c])

这是 Jensen gap。ICG 正是**因为**意识到这点才选择**采样**随机条件（无偏估计），而不是取均值（有偏）。所以"均值 = 真正的平均条件基线"这个说法，**在数学上是错的**；它只是一个碰巧落在分布中心的点。

更糟的是高维几何。我做了数值模拟（4096 维，模拟 VLM 特征）：

```
mean ||real sample||      : 69.85
||mean vector||           : 19.18      <- 均值向量范数只有真实样本的 27.5%
||std=0.02 init|| (4096d) : 1.28       <- 现状确实严重偏小
avg dist sample->mean     : 67.17      <- 均值离任何真实样本仍然很远
avg dist sample->sample   : 94.93
```

两个读数：
1. **现状 `std=0.02` 确实病态**：范数 1.28 vs 真实条件 ~70，差 50 倍。这说明你的直觉"当前 uncondition 是 OOD"**是对的**。
2. **但均值也不在流形上**：范数只有真实样本的 27.5%，且到任意真实样本的距离（67）几乎和样本间距离（95）同量级。**高维下均值是"谁都不像"的空点**，这正是 [2604.02324](https://arxiv.org/abs/2604.02324) 说的退化子空间问题。

**真正能修复 scale mismatch 的是"匹配二阶矩"（均值+协方差，即 HF 的 `mean_resizing` 做法，或 ICG 的 scale-matched Gaussian），而不是单取均值。**单取均值会得到一个范数过小的向量 —— 方向变了，但"范数不对"这个病没治好。
