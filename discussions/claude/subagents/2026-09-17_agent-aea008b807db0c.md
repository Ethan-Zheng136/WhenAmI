            # regular RMSNorm

## 三、逐项判决

### E1 (adaLN-Zero) → **(a) 已被做过，是常识不是 novelty**

- **精确前作**：[2410.10088](https://arxiv.org/abs/2410.10088)《The Ingredients for Robotic Diffusion Transformers》(Dasari/Mees/Levine, UCB, 2024-10, **Comments 无**, 开源)。明确诊断"默认 cross-attn 注入解释了此前 diffusion policy transformer 的糟糕训练动态"，用 adaLN-Zero 替换，**四路消融 Table III**（Pick Place/Pen Uncap）：adaLN-Zero 50%/100%；No Zero-Init 38%/80%；Cross-Attn(10步) 0%/0%；**In-Context(100步) 0%/0%**。E1 的诊断叙事、实验设计、预期结论，这篇全占了。
- **两条机器人上的反证（方向相反）**：
  - **Dita** [2503.19757](https://arxiv.org/abs/2503.19757) (ICCV 2025) 附录 Table 7，CALVIN ABC→D 无预训练：**Dita(in-context) 2.56 vs "AdaLN DiT" 1.45**。我已逐字核实。
  - **HiMoE-VLA** [2512.05693](https://arxiv.org/abs/2512.05693) (2025-12, MSRA, Comments 无) 附录 C.8 三路：Concatenation 4.012 > AdaLN 3.995 > Cross-Attn 3.915，几乎打平且 in-context 略胜。并警告：改注入拓扑会破坏预训练权重复用，公平对比必须从头训。
- **唯一站得住的窄空白**：解释"为何同一改动在 DiT-Block Policy 上救活、在 Dita/HiMoE 上无效"。要立住必须给 **WoG 特有的失效证据**（token-0 的 timestep 信息在末层还剩多少、动作误差是否随 t 呈平坦曲线），不能只引 DiT 的 FID；且**必须把 plain adaLN 作为第三臂**。

### E2 (mutual visibility) → **(a) 已被做过 —— 且结论与直觉相反**

OpenWAM Table 2（RoboTwin2.0-Full 成功率 Clean/Randomized/**Avg**）：

| mask | Avg |
|---|---|
| Isolated | **87.41** |
| Video Sees Action | 87.63 |
| **Action Sees Video** | **92.39** |
| **Mutual** | 92.15 |

**你的 87.41 vs 92.39 完全属实。** 定义（Sec 3.1 Eq 1）：2×2 分块，块内固定（V 首帧因果、A 双向），四种模式=两个交叉块的开关。**是混合自注意力，不是 cross-attention。**

**关键反转（Sec 4.3.3）**：从头训时 Mutual 比 Action-Sees-Video **差 0.24pp**；**经过具身预训练后翻转**：+0.16pp / C2R ID +0.70pp / OOD +0.72pp。OpenWAM 最终配方采用 Mutual，Finding 3："At pretrained scale, mutual world-action visibility is consistently preferred."

**对 E2 最致命的一点**：OpenWAM 的 Tri-System 明确把 VLM 语义流设为"**read-only tail**——其他流可以 attend 它，它只 attend 自己"，即**刻意不给 VLM 流反向可见性**，且**没有消融打开它**。这恰是 E2 最接近的配置。所以 E2 在 world-action 模型上已被系统做过，残留空白仅是"VLM 语义流是否也该双向"这一格。

补充：WorldVLA (2506.21539) 的 attention mask 是 **action-action 掩蔽防误差累积**，与 E2 的跨条件可见性是不同问题，不构成前作。

### E3 (differentiated condition dropout) → **(c) 部分做过，有窄空白**

- **已被做过的核心论点**：除 Composer 外，**V-Express** [2406.02511](https://arxiv.org/abs/2406.02511)（腾讯, 2024-06, Comments 无, 开源）标题即《Conditional Dropout》，明确提出 **shortcut** 框架——"强条件干扰导致弱条件难以生效"，实现 V-Kps 50% / reference 20% **非对称速率**，弱条件 audio 不丢。这是 E3 的镜像结构。
- 其他非对称先例：unCLIP (2204.06125) 10%/50%；UniControl (2305.11147, NeurIPS 2023) 丢 30% text "to enhance the controllability of input visual conditions"。InstructPix2Pix (2211.09800) 则是均匀 5%/5%/5% 的反例。
- **真空白**：无任何 VLA 论文报告过条件 dropout 率的差异化消融；Composer 与 V-Express 均只给单点经验值、**无消融曲线**；且所有先例都在"高→更高"区间，**WoG 的 0.0 这个边界从未被研究**。
- **最大技术风险，必须预先回应**：**History-Guided Video Diffusion** [2502.06764](https://arxiv.org/abs/2502.06764)（MIT, **Comments: "ICML 2025"**）带消融地证明对多帧富信息条件做**二值 dropout 是次优的，且 token 越多越差**（"framewise binary dropout a suboptimal choice"，DFoT FVD 181.6 vs Binary-Dropout 196.0），替代方案是 per-frame 连续噪声。**`O^c` 恰是 16 个 token。**

## 四、两处对你前提的代码级更正

读 github.com/Selen-Suyue/WoG 的 `action_model/models.py` 发现：

1. **cross-attn 不是"xavier 初值没动过"，而是 zero-init by design。** 第141-145行注释 `# zero initialization trick`，把 `in_proj_weight/in_proj_bias/out_proj.weight/out_proj.bias` 全置 0.0。所以"门开度 7%"是**零初始化门只打开了一部分**，而非初始化失败。这实际上意味着 WoG 的 cross-attn **已经是 adaLN-Zero 式的零初始化门控**——E1 想引入的"zero-init 收益"在 O^c 通路上已部分存在。
2. **`obs_dropout_prob` 默认值是 0.75**（models.py:192），但被 action_model.py:38 覆写为 `0 if train_venc else 1`。即 O^c 的 dropout 是**训练阶段相关的开关**（0 或 1），不是简单的"不 dropout"。E3 的表述应据此修正。

另：WoG 正文中 "adaLN" 和 "dropout" 各出现 **0 次**——这两个设计选择论文从未论证过，这本身是可攻击点。
