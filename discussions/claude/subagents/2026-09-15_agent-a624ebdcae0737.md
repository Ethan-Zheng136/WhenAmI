### 1.3 核心技术分歧

**(a) VQ 离散 vs 连续 —— 这是最大的分歧，且 2026 年出现了实证裁决**

- **离散派**：LAPO / Genie / LAPA / Moto / IGOR / GO-1。VQ-VAE 提供硬信息瓶颈，天然适配自回归 next-token 训练。
- **连续派**：CoMo / CLAM / villa-X / Meta 的 in-the-wild LAM。
- **裁决一（Meta, [2601.05230](https://arxiv.org/abs/2601.05230)）**：LeCun/Rabbat/Garrido 组明确写道 *"continuous, but constrained, latent actions are able to capture the complexity of actions from in-the-wild videos, something that the common vector quantization does not"* —— 在真实野外视频上 **VQ 直接不够用**。
- **裁决二（What Matters, [2608.19613](https://arxiv.org/abs/2608.19613)）**：更细致。VQ-VAE 在 **LIBERO-Plus 零样本泛化**上最好（0.517 vs AE 0.445 / VAE 0.433 / Sparsity 0.468 / SIGReg 0.467），作者归因于"离散瓶颈鼓励模型学可复用的高层 action primitive"；但在 LIBERO 与 RoboTwin2.0 上 **VQ 整体较差**。结论是 *"VAE 作为默认选择（最简单有效），VQ-VAE 只在零样本泛化是首要目标时优先"*。
- 更关键的发现：**"正则化系数的选择远比选哪种连续正则化方法重要"** —— VAE / Sparsity / SIGReg 在 LIBERO 上成功率仅在 0.908–0.915 之间浮动。这实质上说明这条线上一大批"新正则化方法"论文的贡献在噪声内。

**(b) 是否用 inverse dynamics（IDM-FDM）**

What Matters 把整个领域归为两个范式：
- **隐式 IDM-FDM**：LAPO / LAOF / CoMo —— IDM 从 (o_t, o_{t+1}) 推 latent，FDM 从 (o_t, latent) 重建 o_{t+1}。
- **CFD-AE**（consecutive-frame-differences autoencoding）：不学 IDM，直接对预定义的帧差信号做 autoencode。StaMo 用 DINOv2 语义特征差，Motus 用光流。

**实证排名**（三 benchmark 平均）：LAPO (0.7327) > DINO (0.7280) > CoMo (0.7167) > RGB (0.6973) > LAOF (0.6907) > SEA-RAFT (0.6433) > RAFT (0.6427)。即 **原始 LAPO 仍是最强 baseline，且不需要任何预处理**。

**(c) 是否需要 action-labeled 数据 finetune —— 争议最尖锐处**

- 原始承诺：LAM 纯无监督预训练 + 少量 action 数据解码。
- **Nikulin et al.（[2502.00379](https://arxiv.org/abs/2502.00379), ICML 2025）直接否定了这个 pipeline**：*"integrating supervision during LAM training is critical in the presence of distractors, **challenging the conventional pipeline of first learning LAM and only then decoding from latent to ground-truth actions**"*。仅 **2.5%** ground-truth action 混进 LAM 训练，下游性能提升 **4.2×**。
- LAOF 走"伪监督"折中：用光流当 action-driven 信号，声称无监督也能匹配 1% action label 的有监督方法。
- 但 What Matters 全文测下来 **LAOF 反而一致地降低性能**（0.6907 < LAPO 0.7327）。

**(d) 跨 embodiment 处理**

四条路线：
1. **语言/任务条件化**（UniVLA）：在 DINO 特征空间建 LAM + 语言指令，抑制 task-irrelevant dynamics，得"task-centric" latent。
2. **共享 latent 空间 + per-embodiment 解码器**（IGOR、LAPA）。
3. **注入 proprioceptive FDM**（villa-X）：不只压缩视觉变化，联合建模物理状态转移。
4. **action-based latent**（From Pixels to Tokens 的分类）：把连续 action 压进统一 latent 以桥接异构 action space（反方向）。

Meta 那篇给了一个诚实的负面观察：**在没有共同 embodiment 的野外视频上，学到的 latent action 主要变成"相对于相机局部化的空间量"**（*"latent actions that become localized in space, relative to the camera"*）—— 这直接呼应你的第 3 问。

**五条结论（论文原文编号）**：

2. 各正则化方法调好超参后下游性能相当；给出 5 种集成策略的实操指南。
3. **latent action 维度 = 32 在 7-DoF 单臂和 14-DoF 双臂上都最好**；正则化得当时额外的 latent action normalization 不必要。
4. **FDM 重建 metric 比额外训练的 probe metric 更可靠**；但两者都只适合粗筛，不适合精排。
5. 用 latent action finetune VLM backbone 提供更强初始化；scaling up latent action 预训练一致地改善下游。

## 3. LAM 的已知失效模式：**有，而且证据链非常完整**

这是这条线上最成熟的批判性文献群。**答案是明确的"是"** —— 有多篇论文指出 latent action 学到的是 camera motion / 光流 / 背景变化，且都做了诊断实验。

### 3.1 理论诊断

**What Do Latent Action Models Actually Learn?** — [2506.15691](https://arxiv.org/abs/2506.15691)，2025-05-27（v3 2025-11），Chuheng Zhang / Tim Pearce / Li Zhao / Jiang Bian 等（**MSRA，与 villa-X、IGOR 同组**），**NeurIPS 2025**。
- 方法：把 LAM 的深层组件换成线性层，保留训练难点但可解析。
- 核心结论：**线性 LAM 在一定假设下精确等价于 PCA**。因此**当帧间变化的主要方差来源不是可控信号时，latent 捕获的就是噪声而非 action**。
- 意外发现：**over-parametrization** 问题；以及 **observation 与 action 的相关性会降低 LAM 对可控变化的关注 —— 数据生成策略的随机性越高反而越有利**（这条对"用专家演示数据训 LAM"是个反直觉警告，与 WoG 用 OXE 专家动作的设定直接相关）。
- 缓解：data augmentation（治 over-parametrization）+ action-prediction head。

**Why Latent Actions Fail, and How to Prevent It** — [2605.20223](https://arxiv.org/abs/2605.20223)，2026-05-13，Jung Min Lee / Taehyun Cho / **Li Zhao** / Jungwoo Lee（首尔大 + MSRA）。
- 把上面的线性框架扩展到**显式建模 exogenous state**。
- 两条解析结论：(1) **最小化标准重建目标会产生"从未来观测编码 exogenous 信息"的 latent action**（即 **future leakage**）；(2) 在聚焦 endogenous 成分的表示空间里学习是抑制噪声干扰的关键。
- 并且**证明了** action-supervision 这类辅助目标为何有效：它们 provably 鼓励 latent action 跨 exogenous state 保持一致。

### 3.2 实证诊断（诊断实验的标准范式）

**Latent Action Learning Requires Supervision in the Presence of Distractors** — [2502.00379](https://arxiv.org/abs/2502.00379)，2025-02（v5 2025-06），Nikulin et al.（Dunnolab / AIRI），**ICML 2025 poster**，代码 [dunnolab/laom](https://github.com/dunnolab/laom) ✓。
- **这是该问题的规范参考**。用 **Distracting Control Suite (DCS)**，distractor 恰好就是你问的三类：**动态背景视频、相机抖动（camera shaking）、agent 颜色变化**。
- 诊断工具：**linear probing** —— 训一个线性 probe 把 latent action 映到 ground-truth action，梯度不回传，用 MSE 衡量。这已成为该子领域的标准诊断指标。
- 结论：LAPO 在 distractor 下失效；架构修补（multi-step IDM、去量化、latent-space FDM、augmentation）把 latent 质量提 **8×** 但仍不够；**2.5% ground-truth action → 下游 4.2×**。

**MaskLAM / Segment to Focus** — [2602.02259](https://arxiv.org/abs/2602.02259)，2026-02-02（v2 2026-05-27），Fechner / Jackson / Zöllner 等。
- 明确表述失效机制：*"the standard reconstruction objective drives latent actions to encode **exogenous motion** instead of agent-controlled dynamics"*，distractor 举例就是 **dynamic backgrounds, camera shake, other moving objects**。
- 关键洞察 + 诊断：endogenous 与 exogenous 因子在**像素空间是空间可分的**。于是用 SAM 零样本拿 agent mask，把重建目标限制在 agent 像素上。
- 结果：linear-probe MSE 降 **3.51×**，normalized return 升 **4.97×**（vs LAPO）。无需架构改动、无需 action label。

**Latent Actions from Factorized Transition Effects under Agent Ambiguity** — [2606.30544](https://arxiv.org/abs/2606.30544)，2026-06-29（v2 2026-07），Nam / Balestriero 等（Brown）。
- 最直接命中你的提问：*"observations contain not only agent motion but also **distractors, camera dynamics, and background changes**, making recovery of the underlying action **intrinsically ambiguous** without supervision"*。
- 提出一个概念转向：**无监督情形下合适的目标不应是 true action 本身，而是 transition effect 的 state-conditioned 组合摘要**。

**Meta 的野外实验（最重要的"承认"）** — [2601.05230](https://arxiv.org/abs/2601.05230)，2026-01-08，Garrido / Nagarajan / Ballas / **LeCun** / Rabbat（FAIR），**ICML 2026**，37 页。
- 在真实野外视频（非游戏/非仿真/非 manipulation）上跑 LAM。诚实结论：**"在缺乏跨视频共同 embodiment 的情况下，我们主要只能学到相对于相机在空间上局部化的 latent action"** —— 这几乎就是你假设的"学到的是 camera-relative 的东西"的直接确认，且出自最有资源的团队。

### 3.3 其他失效模式变体

- **appearance shortcut**：ConLA（[2602.00557](https://arxiv.org/abs/2602.00557)，2026-01-31）指 VQ-VAE 类方法训练目标偏重重建视觉外观而非帧间动力学，导致依赖 spurious visual cue、表示纠缠。
- **causal leakage / future leakage**：CoMo（[2505.17006](https://arxiv.org/abs/2505.17006)）通过把 FDM 的未来帧输入替换为帧差来缓解 IDM 直接编码未来帧信息。What Matters 描述最坏情形是 latent *"even degenerate into a direct feature of the future frame itself"*。
- **magnitude miscalibration**：AC-LAM（[2604.03340](https://arxiv.org/abs/2604.03340)，2026-04-03，MSRA 系）指 latent 会 *"miscalibrate motion magnitude"*，用加法组合性约束（identity / inverse / cycle consistency）治。
- **viewpoint 敏感**：VILA（[2601.02994](https://arxiv.org/abs/2601.02994)）；MVP-LAM（[2602.03668](https://arxiv.org/abs/2602.03668)）用跨视角重建强制 latent 不依赖视角特定线索，并用**与 ground-truth action 的互信息**作为诊断指标。
- **VLA-JEPA 的批评**（[2602.10098](https://arxiv.org/abs/2602.10098)，2026-02）：断言即使**加了光流约束的变体仍然把可控动力学与相机运动、背景变化纠缠在一起**。

### 3.4 最强的表示级诊断：LARY benchmark

**LARY** — [2604.11689](https://arxiv.org/abs/2604.11689)，2026-04-13，美团（Meituan，Xunliang Cai 组）。1.2M 样本 / 151 类动作 / 11 种 embodiment / 620K 图像对 / 595K 轨迹。设计上**把 latent action 表示评估与下游 policy 性能解耦**（用 attentive probing + regression）。

我从全文表格抓到的实测数字（Action Classification，Avg. 列）：

| 模型 | 类型 | Params(M) | Avg. |
|---|---|---|---|
| V-JEPA 2 | Semantic Encoder | 303.89 | **76.62** |
| DINOv3 | Semantic Encoder | 303.13 | 68.68 |
| Wan2.2 | Pixel Encoder | 704.69 | 49.36 |
| FLUX.2-dev | Pixel Encoder | 84.05 | 47.48 |
| LAPA-DINOv2 | General LAM | 473.69 | 49.36 |
| LAPA-SigLIP2 | General LAM | 200.83 | 43.67 |
| **LAPA** | **Embodied LAM** | 343.80 | **20.17** |
| **UniVLA** | **Embodied LAM** | 287.75 | **17.99** |
| **villa-X** | **Embodied LAM** | 238.71 | **20.90** |

**这张表是这条线目前最尖锐的负面结果**：三个旗舰 embodied LAM 全部在 18–21 区间，而**零动作监督的通用视觉编码器 V-JEPA 2 达 76.62（约 3.8×）**。原文措辞：*"current embodied-specific training not only fails to leverage powerful visual priors but **may actually constrain representation quality**"*。

但 LARY 也给了 LAM 一个**辩护**：做 stride ablation 时，通用编码器在短时程极好（stride=5 时 MSE 0.04）但**长时程灾难性失败（stride=30 时 MSE 飙到 0.62）**，而 LAM（embodied 与 General 都是）**在所有 stride 上保持稳定**。原文结论：*"the latent action paradigm does not merely encode static spatial alignments; instead, it successfully captures and preserves underlying dynamic action trajectories"* —— 只是 embodied LAM 的绝对误差高（平均 MSE ~0.70）。

**这个"短时程弱、长时程稳"的分离，是我认为整条线最有价值的未被充分利用的发现。**

## 4. LAM vs "预测未来观测当辅助目标"（WoG / VPP 线）

### 4.1 有头对头比较，但**没有一篇是干净的双向对照**

| 论文 | 对照设计 | 结论 | 是否干净 |
|---|---|---|---|
| **VPP** [2412.14803](https://arxiv.org/abs/2412.14803)（ICML 2025 Spotlight，清华 Jianyu Chen 组，代码 ✓）| 换 **encoder**（VC-1、Voltron）；去 video 预训练；去 Video Former | 预测式表示胜出 | **不干净** —— 对照的是 encoder，**不是 latent action pipeline**。不能从中读出 LAM 的判决 |
| **ViPRA** [2511.07732](https://arxiv.org/abs/2511.07732)（**ICLR 2026**，CMU Pathak 组，代码+模型已放）| **同时**训 future observation 预测 + motion-centric latent action | 二者互补。明确批评前作 *"prior latent action works treat pretraining as autoregressive policy learning"*，自称 *"explicitly models both **what changes and how**"*。SIMPLER +16%，真机 +13% | **最接近头对头**，但是"A vs A+B"而非"A vs B" |
| **VLAFlow** [2607.01586](https://arxiv.org/abs/2607.01586)（2026-07，v2 2026-08）| **架构完全受控**：同一 π0-style 架构、同一 VLM backbone、同一 action expert、同一 14-D action space，在 ~5000 小时 OXEMix 上对比 4 种范式：action-only / language co-train / **future latent alignment** / 组合 | future latent alignment 改善状态转移与 action-outcome 建模；language supervision 保住 VL 泛化；**组合最稳** | **控制最严格的一篇**，但对照组里**没有 latent action**（是 language vs future-latent）|
| **What Makes Video World Model Latents Action-Relevant: Prediction over Reconstruction** [2606.07687](https://arxiv.org/abs/2606.07687)（2026-06-05，首尔大 Taesup Kim 组）| 统一 IDM probing，跨 8 个 encoder family | **最有理论价值的一篇**：action-relevant 结构主要来自**时序视频预训练**，而非像素重建保真度 —— *"models with strong pixel decoding quality can exhibit **near-zero action recoverability**"*。V-JEPA vs VideoMAE 对比显示增益主要来自自然视频的时序上下文，feature-level latent prediction 只有较小额外收益 | 是 probe 层面而非 closed-loop |

### 4.2 理论取舍

**这两条线在 2026 年已经不是"竞争"关系，而是被重新理解为同一坐标轴上的两个点。** 关键坐标是：**监督信号在"压缩程度"轴上放在哪里**。

```
原始像素未来帧 ←————————————————→ 极度压缩的 latent action
(VPP / 视频生成 WAM)      (LAPA / VQ latent)
   ↑ 冗余、算力贵、           ↑ 丢细粒度、
     建模无关视觉细节           被 exogenous 噪声污染
                ↑
        中间地带（2026 年的主流答案）
   future latent state / JEPA-style / continuous constrained LA
```

**LAM 侧的代价（有文献支持）**：
- 压缩过狠丢细粒度 —— From Human Videos 综述（[2606.00054](https://arxiv.org/abs/2606.00054)，**IJCAI 2026 Survey Track**）把这条直接列为开放问题：高度压缩的 latent token 能否充分表示复杂高 DoF 灵巧操作的丰富结构。LARY 的 18–21% 与 ~0.70 MSE 是这条的量化证据。
- 瓶颈只约束了信息**量**，没约束信息**类型** —— 于是省下来的容量优先编码方差最大的 exogenous 变化（§3 全部文献）。

**未来观测侧的代价（有文献支持）**：
- **DELE-w0.5**（[2608.22067](https://arxiv.org/abs/2608.22067)，2026-08，深圳 DeepLeap）措辞最直白：*"video generation is an **unnecessary intermediate objective** for world-action modeling"*、*"intermediate frames ... consume substantial model capacity and computation, but do not directly specify the physical outcome"*。真机 640 次试验，full-task 成功率 62.5%，超最强 baseline **32.5 个百分点**。
- **Being-H0.7**（[2605.00078](https://arxiv.org/abs/2605.00078)，2026-04-30，北大 Zongqing Lu 组）：*"pixel-space prediction is a costly and indirect substrate for control, as it may model visual details irrelevant to action generation"*。方案是 prior/posterior 双分支在 latent 空间对齐，部署时丢掉 posterior、**不做任何 visual rollout**。
- **LAWA**（[2608.24882](https://arxiv.org/abs/2608.24882)，2026-08-25，v2 2026-09-01 —— 目前最新）：给出了这个 trade-off 的**量化三角**。它先反驳"直接砍掉未来预测"（Fast-WAM）：matched 实现下 Fast-WAM 泛化更差，**尤其在机器人演示稀缺和 OOD 场景**。然后用 compact latent action 当"未来意图的操作性表示"，推理时省掉 future-video 分支：RoboCasa few-shot 65.6% / full 80.8%，比 matched Fast-WAM 高 **9.6 / 4.5** 点，同时比 Joint-WAM **降低 42.9% 推理延迟**。结论句值得记住：*"**future imagination need not be discarded**: retaining it with compact latent actions yields an effective trade-off among performance, generalization, and latency"*。
- **MoLA**（[2605.12167](https://arxiv.org/abs/2605.12167)，**ICML 2026**）指出核心错配：*"predicted observations emphasize **perceptual fidelity rather than action-centric causes** of state transitions"* —— 视觉真实性与控制相关性之间的错配。

**综合判断**：2026 年的证据不支持"哪条线更好"，而支持一个更强的命题 —— **两条线各自的失效模式是同一个病的两面：监督目标与"控制相关性"不对齐。** LAM 病在压缩时不知道该丢什么（丢了细粒度、留了 exogenous）；未来观测预测病在不压缩时不知道该学什么（把容量花在无关视觉细节）。[2606.07687](https://arxiv.org/abs/2606.07687) 的 *"prediction over reconstruction"* 和 [2605.20223](https://arxiv.org/abs/2605.20223) 的"要在聚焦 endogenous 的表示空间里学"是从两侧给出的同一个答案。**2026 下半年的收敛点是"在 latent 空间预测未来状态"**（Being-H0.7 / VLA-JEPA / DELE-w0.5 / LAWA），这恰好是 WoG 那条线的自然落点。

**对 WoG 的具体启示**：如果 WoG 的辅助目标是在原始观测空间预测未来，[2606.07687](https://arxiv.org/abs/2606.07687) 的结论（像素解码质量与 action recoverability 可以近乎正交）意味着 **WoG 的重建指标可能与其真实收益脱钩**，需要单独用 IDM probing 验证。另外它有一条对 WoG 直接有利的发现：**inverse-dynamics 监督显著提升对视觉损坏的鲁棒性**，说明 action-aware 目标在干净设置之外还起到正则化 latent 几何的作用。
