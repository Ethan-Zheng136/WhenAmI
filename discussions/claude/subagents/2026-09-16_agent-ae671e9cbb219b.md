## 六、我这个 scope 的裁决（brutally honest）

**具身/VLA 社区是否已经做过这件事？—— 分三层回答：**

3. **"conditional on student z"层（`O^c − Proj(O^c|z)`、conditional-MI、相对 z 的正交惩罚）：我没有找到任何具身/VLA 论文这么做。这是真实的空白。** 但空白很窄，而且有一个严重的 prior-art 风险：

**最接近的工作（按威胁程度排序）：**

- **① WoG 2602.22010 自己（最大威胁，因为它就是你要改进的对象）。** 它的 stage-1 是 `P(A|z, O^c)`，原文自陈 O^c 提供 "**complementary** conditions"，并明确提出判据"该空间的信息应当是 action 生成的充分且有效条件"。换言之 **WoG 已经通过架构（z 与 O^c 联合进 action head）隐式实现了"只保留 z 之外有用的部分"**。你的显式 loss 在 WoG 作者看来会被描述为"我们已经做了，只是不用额外的 loss"。**你必须做的实验：证明 WoG 的隐式 conditioning 不充分 —— 即实测 `I(O^c; z)` 很高 / `O^c` 中相当比例的方差可被 z 线性预测，并证明显式 project-out 带来增益。没有这个测量，这篇论文站不住。**

- **② ForeTime-VLA 2608.20735（最大的机制重叠）。** 已在 teacher target 上做了 delta + whitening + off-diagonal covariance。审稿人会问："你与 `f_t − c_t` + whitening 的差别只是把 `c_t` 换成 `z`？" 你的回答必须是量化的：**减 `c_t`（冻结的、与 policy 无关的当前特征）与减 `Proj(·|z)`（policy backbone 实际已编码的内容）之间的差距有多大**。注意 z ⊋ c_t 的信息（z 还含 language、proprioception、历史、以及 VLM 的语义抽象），所以这个差距在原理上是实在的 —— 但你需要实证。

- **③ 2609.02046 Modeling What Changes** 抢先占了 "residual world model / predict only what changes" 这个 framing 和 naming。**不要用这类标题。**

**精确的 residual gap（你唯一能主张的东西）：**

> 在 VLA 的 future-prediction 辅助目标中，**把 distillation target 显式地相对 student policy 表征 z 做条件最小化** —— 即通过 `Proj(O^c|z)` 投影消除、或对 teacher 施加 `I(O^c; z)` / 正交约束，使 loss 的梯度只由 "z 尚未编码且 action 仍需要" 的残差成分驱动。

> 现有工作的去冗余全部是 **unconditional / heuristic / policy-agnostic**（减冻结的当前帧特征、减静态区域、减非光流区域、减纹理、per-dimension whitening 防坍缩），或是 **implicit-architectural**（WoG 的 `P(A|z,O^c)` 联合条件、ForeTime 的共享 action decoder）。**没有人把 "z 已知" 这件事写进 target 的定义里，也没有人量化过 teacher target 中被 z 解释掉的比例。**
