# 二、B2 判决：**(a) 已做 —— 而且是 2022 年就解决了的标准做法**

这是最硬的坏消息。两条 ar5iv 原文实锤：

**Flamingo (NeurIPS 2022), §2.1 原文：**
> "For video inputs, frames are sampled at 1 FPS and encoded independently to obtain a 3D spatio-temporal grid of features **to which learned temporal embeddings are added**. Features are then flattened to 1D before being fed to the Perceiver Resampler."

**Video-LLaMA (EMNLP 2023 demo), §2.1.1 原文：**
> "**Since the frame representations v_i from the frozen image encoder are computed without considering any temporal information, we further apply position embeddings as the indicator of temporal information to the representations from different frames.** Then, we feed the position-encoded frame representations to Video Q-former, which shares the same architecture with Query Transformer (Q-Former) in BLIP-2."

即：**"Perceiver/Q-Former 的 KV 侧对帧是无序集合，必须加 temporal embedding" 这件事，Flamingo 和 Video-LLaMA 都不是"顺带做了"，而是明确写出动机后做的。** 你描述的 B2 与 Video-LLaMA 的做法在架构位置上逐字同构（加在送入 Q-Former 交叉注意力之前的 KV 侧）。

**"置换不变性"这个论断本身也已被形式化并实验验证：** STEP (ICRA 2026, [2503.24298](https://arxiv.org/abs/2503.24298)) 摘要原文 "our analysis shows that **probing is permutation-invariant and blind to frame order**"，其解法 = frame-wise positional encodings + global CLS + 简化注意力块，在近对称动作（拿起 vs 放下、开 vs 关抽屉）上涨 4–10%。这正是你想给 B2 讲的故事，只不过发生在动作识别而非 VLA。另有 VRoPE (EMNLP 2025) 做视频 LLM 的时序位置编码设计。

**诚实结论：B2 不是开放问题，是 WoG 的实现疏漏。** 好消息只有一条：它是"别的领域已解决、在 VLA future-condition 编码器上恰好没人写"（技术上算 (b)），但这条缝太窄——审稿人会直接说 "add positional encoding, known since Flamingo"。

**建议定位：** B2 不能当 contribution，只能当 **诊断 + 修复的实证证据**。要让它站住，唯一能加分的实验是 *permutation test*：把 5 帧 KV 顺序打乱/倒序喂给已训好的 WoG，如果 O^c 和最终动作几乎不变（复刻 STEP 的 shuffle/reverse 诊断），你就有了"SOTA VLA 的世界模型条件其实对时间方向完全失明"的硬证据。那是个有说服力的 finding，但它的价值在**揭示基线缺陷**，不在**方法新颖性**。

# 三、B3 判决：**(c) 大部分已做，剩余缝隙很窄**

事件驱动/非均匀关键帧选择这条路线已经被反复走过，而且**KEMO 直接做了你想做的那个 ablation**：

> KEMO 摘要原文："**Ablations show that event-driven keyframe selection outperforms uniform sampling and recent-frame retention**, while the proposed gated fusion and keyframe-aligned loss weighting provide complementary gains."

而且 KEMO 的机制与 B3 几乎一一对应：用**机器人运动学（夹爪状态）+ 视觉过滤检测 event** → 选关键帧 → 编码成**紧凑的、带时序顺序的 memory token** → 通过 **cross-attention + gated residual fusion** 融入 VLA。注意它还同时覆盖了 B2（"temporally ordered memory tokens"）。

各论文与 B3 的精确关系：

- **KEMO** [2606.23589]：事件驱动关键帧 + 时序有序 token + 交叉注意力。**关键差异：KEMO 选的是过去帧（memory），B3 选的是未来帧（condition/guidance）。** 这是目前 B3 唯一实质性的剩余空间。
- **AWE** [2307.14326]：用"线性可插值"准则自动抽取 waypoint，把决策 horizon 缩短 10 倍。是**动作侧**的非均匀时间抽象，不是视觉条件侧。但"均匀采样不是最优时间抽象"这个 claim 它 2023 年就立了。
- **UVD** [2310.08581]：用预训练视觉表征的 **embedding 空间相变（phase shift）**无监督发现 subgoal，零额外训练开销。**这是 B3"非均匀选帧"的最强通用先例**，而且是纯视觉、off-the-shelf——直接可以套到 WoG 的未来帧选择上。如果你做 B3，审稿人第一个问题就是"和 UVD 选帧有什么区别"。
- **SuSIE** [2310.10639]：固定间隔（约 20–24 步）生成 subgoal。**它是被批评的那一方，不是先例。**
- **TaKSIE** (WACV 2025) [2410.11013]：明确指出 SuSIE 固定间隔的问题——"固定间隔策略在关键状态沿轨迹位置变化、演示速度不一时表现差"，改用**任务进度表征自适应采样下一个 subgoal**。这是 "均匀/固定 → 自适应" 的直接同构工作。
- **CLOVER** (NeurIPS 2024) [2409.09016]：同样批评 SuSIE 的 subgoal 刷新间隔是数据集相关的手工超参，"limiting performance and scalability"。
- **AHA-WAM** [2606.09811]：与 B3 的"多尺度 horizon"最接近的当代工作。核心主张——"现有 world-action model 把世界预测和动作执行绑在**同一时间分辨率**上，迫使 world 分支建模冗余且弱信息的近期帧变化"——**这几乎就是你想对 WoG 的均匀采样提出的批评**。它的解法是异步双 DiT（低频 world planner + 高频 action DiT）+ horizon-adaptive offset 训练 + OVCR 路由。
- **X-Foresight** [2605.24892]：**chunk-wise 长程自回归 + temporal importance sampling**（把监督集中在由 ego-motion 和行为信号识别出的安全关键 chunk 上）。"按事件重要性分配时间采样预算"这个思想已被它占掉，只是在自动驾驶域。

**B3 剩余的精确缝隙（唯一可辩护的表述）：**
> "在**压缩式未来条件编码器**（把未来帧压成 compact condition 作为 DiT 每层 cross-attn KV）这一具体架构下，**喂哪些未来帧**从未被系统消融；已有的事件驱动选帧工作（KEMO）针对的是过去记忆，已有的自适应 subgoal 工作（TaKSIE/CLOVER）针对的是单张生成式 subgoal 图像，两者都不涉及多帧压缩条件。"

这条缝能不能撑起一篇 paper 取决于**效果幅度**。要让它站住必须有的实验：在 WoG 上做严格的选帧策略矩阵（uniform / UVD-style 表征相变 / 夹爪事件 / 多尺度 log 间隔 / 随机），固定其他一切，报告成功率 + O^c 的信息量指标；并且**必须在长程、多阶段任务上**显示均匀采样确实漏掉关键转换——否则就是在已被占满的赛道上加一格。

# 四、B1 判决：**(d) 基本开放，但它不是 novelty，是 bug fix**

**没有找到任何学术论文**专门报告"episode 末端 goal index clamp 导致未来帧塌缩成重复末帧"及其训练影响。搜索 arXiv（OXE/RLDS 数据质量、terminal frame repetition、episode boundary padding）全部空返回；只在工程博客/LeRobot 文档层面有讨论：LeRobot 类数据集在 episode 边界"自动 padding 并返回 pad flag"，实践共识是**要么 mask 掉 padded target，要么把采样窗口截断在 `len(ep) - action_horizon` 内**。

也就是说：**pad_mask 是数据加载器的标准实践（LeRobot 已内置 pad flag），只是 WoG 没用。** 这是个真 bug，修了大概率涨点（尤其是末端行为/过早停止），但：

- 它不可能作为 contribution 发表；
- 它的价值是**让 B2/B3 的实验干净**——如果不修 B1，你在 B2/B3 上测到的任何"时序信息有用"的增益，都可能被审稿人归因为"你只是修了重复帧"。

**强烈建议：B1 必须先修，且作为所有后续实验的共同基线**，而不是作为三个并列的"改进点"之一。否则三者混淆，实验不可归因。

# 五、额外发现：对 (5) 帧数消融的回答

没有找到"3 vs 5 vs 8 帧喂给条件编码器"的直接消融。最接近的几个（均已验证）都在**别的轴**上做消融：

- **RAF-VLA** [2609.17728]：消融未来对齐 **horizon**（1s vs 4s）和**每个 horizon 的 world query 数**（K=4 最优，超过 4 无增益）——注意这个 K=4 与 WoG 的 16 queries 是同类超参。
- **OneWM-VLA**（One Token Per Frame）[2605.07931]：**把每帧压到 1 个 token 而长程性能不降**。这对你是个警告信号：如果每帧 1 token 就够，那么 WoG 的 5×72=288 KV token 里真正起作用的可能极少，**B2/B3 的增益空间可能被"容量本来就过剩"吃掉**。这篇必须读，它可能直接削弱你的立论。
- **PACT-WAM** [2602.15882]：**分层历史编码**——早期观测给粗空间表征、近期观测给细表征，16 帧 256 token/view，比 dense 少 75%；消融显示"hierarchical history allocation"有效。这是"**非均匀分配 token 预算给不同时间距离的帧**"，思想上与 B3 高度重叠，只是在过去侧。
- **PHR-VLA** [2608.27609]：消融了视角、粒度（patch vs mean）、target 形式、编码器、loss 权重——**唯独没扫 horizon H**。
- **X-Foresight**：消融 frame-wise vs chunk-wise、stride 1s→3s 的课程。
