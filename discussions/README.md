# WhenAmI / WoG — agent discussion archive

Readable Markdown exports of the Claude Code and Codex CLI sessions in which the WhenAmI project (a VLA built on WoG) was discussed, designed, and implemented.

- Source: the `~/.claude/projects/` and `~/.codex/sessions/` transcripts on the training server. Only WhenAmI/WoG sessions are included. Sessions about other projects (TRELLIS, vehicle 3D reconstruction, FAV, startup handoffs, a résumé, a homepage) were left out.
- Each file has the user and assistant messages in order. Tool calls and outputs are kept but capped at 2,000 characters each. Thinking blocks and images are dropped.
- Resumed or forked Claude sessions repeat earlier history, so messages were de-duplicated across forks. Later forks contain only their new messages.
- Redaction (the repo is public): tokens, API keys, auth headers, credential-bearing URLs, `*TOKEN/SECRET/PASSWORD=` values, private IPs, and internal hostnames are replaced with `[REDACTED]`. Some harmless code identifiers that contain `token` were also redacted by the conservative regex.
- Times are Beijing time (UTC+8). Files over 8 MB are split into `.partN.md`.

Project design docs (`WHENAMI_*.md`, `PLAN*.md`, `stage3/RESEARCH_DISCUSSION_20261002.md`, and others) live in the code tree on the `main`, `present_token`, and `timeline_force` branches.
